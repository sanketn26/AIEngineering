# Specialization Tracks

Ninety-day, project-shaped paths that reuse the [core modules](../index.md). Complete [Setup](../getting-started/setup.md) first.

| Track | Outcome | Core dependencies |
|-------|---------|-------------------|
| [Stock recommender](stock-recommender.md) | End-to-end recommendation system with RAG, SLM/Phi, compression, MLOps | 01–07, 09–10, 13, 17 |
| [Hybrid models](hybrid-models.md) | Custom Transformer+MLP architecture in PyTorch | 05–06 + DL fundamentals |
| [Agentic editor plugin](agentic-plugin.md) | VS Code extension orchestrating agents + local models | 01–05, 07–08, 11–12, 17 |

## How to run a track

1. Skim the track’s phase table end-to-end.  
2. Map each phase to core modules; close gaps first.  
3. Keep `PROGRESS.md` and ship **phase deliverables**, not only notes.  
4. Prefer open models + reproducible scripts in the repo.  

## Shared engineering bar

- Version control from day 1  
- Tests for non-LLM code; evals for LLM behavior  
- README with setup, limits, and ethics notes (especially finance track)  
- No secrets in git
